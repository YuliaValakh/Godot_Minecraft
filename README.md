# Godot 4 3D Voxel Game

A simple 3D voxel game clone built in Godot 4, inspired by Minecraft.

## Features
* 3D Voxel World: Basic implementation of voxel-based terrain and block layouts.
* Player Interaction: Allows the player to move around, select different blocks, and destroy or place them in the world.
* Game Interface: Features a functional main menu system (New Game / Quit).

## Tech Stack
* Game Engine: Godot 4
* Language: GDScript
